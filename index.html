About me

I’m a front-end developer with a strong STEM background. I like turning raw data and rough requirements into something people can use: a responsive page, a chart, a SQL database, or a Python script.

I studied STEM because I love understanding how systems work, from physics and chemistry to technology. It taught me to work under pressure, collaborate, manage my time, and meet deadlines. I later joined E-JUST (Egypt-Japan University of Science and Technology) on a scholarship for excellence, where I keep strengthening my technical and problem-solving skills.

CPU Scheduling Simulator: Priority vs SRTF

A responsive CPU scheduling simulator that visualizes Priority vs SRTF (preemptive), including Gantt charts and performance metrics.

What it is
A web-based simulator that compares preemptive Priority Scheduling and SRTF (Shortest Remaining Time First) on the same set of processes.
My role
Front-end UI and the scheduling visualization logic.
Tools
  • HTML
  • CSS
  • JavaScript
Key features
  • Side-by-side algorithm comparison
  • Interactive Gantt chart visualization
  • Preemptive scheduling support
  • Performance metrics: CT, WT, TAT, RT
  • Random process generator with validation
  • Responsive design for desktop and tablet
Outcome
Helps people see how each algorithm behaves and compare the results through metrics and Gantt charts.
